完美转发

  • 转发：把一个函数的形参（限定为引用类型，避免拷贝原始对象、不强迫调用者传指针）传递给另一个函数，目标是让被转发的函数拿到和原始调用完全相同的对象。
  • 完美：不仅转发对象本身，还转发对象的核心特征 —— 类型、是左值 / 右值、是否 const/volatile。
  • 实现方式：通过 “通用引用”+std::forward实现，通常写成可变模板（支持任意数量参数），模板结构如下：
  • 失败判定：直接调用f(表达式)和通过fwd(表达式)调用的行为不一致（编译失败 / 执行逻辑不同），就说明完美转发失败了。

2. 0 或 NULL 作为空指针

  • 原因：模板推导会把 0/NULL 推导为整型（如 int），而非指针类型，导致转发给需要指针的函数时类型不匹配。
  • 解决方案：用nullptr代替 0/NULL。

总结

  1. 完美转发失败的原因是：模板类型推导失败，或推导出 “错误类型”（导致转发行为与直接调用不一致）。
  2. 五类典型失败场景：花括号初始化器、0/NULL 空指针、仅声明的整型 static const 成员、重载 / 模板函数名、位域。
  3. 所有失败场景都有简单解决方案，思路是消除 “推导歧义” 或 “寻址 / 绑定限制”（如显式类型推导、拷贝副本、使用标准空指针等）。
